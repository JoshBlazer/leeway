## The simulator found real bugs in the correct code

This is the most valuable result of the milestone. The first catch-rate report said 100%, and it was **meaningless**: the correct code was failing too, so seed 1 "caught" everything. A mutant now only counts as caught if the correct code passes the same schedule.

| Round | Soak result | Cause | Fix |
|---|---|---|---|
| 1 | About a third of runs failed | An acknowledged add left the view before a pull included it, so the next add lost an increment | Settling deltas |
| 2 | 9 of 10,000 | Shuffled delivery could raise a per-device clock offset between two writes | Dropped offsets |
| 3 | 9 of 50,000 | A late arrival clamped against a raised watermark landed above an earlier write | Place each write between its neighbours |
| 4 | 0 of 200,000 | | |

For round 2, my own design note had dismissed this as a corner the simulator's single register could not show. That was wrong, and the shrinker showed it in an 11-event schedule. The bugs were all invisible to the property tests of M1.

The fixes are explained in `docs/design/hlc.md` and `merge-semantics.md`, and ADR-0014 records the decision.

## Limits

- **The simulator tests the protocol on a modelled transport, not the Datasync adapters.** A bug in `Leeway.Datasync.Server` will not show up here. See `m3.md` for how those are tested.
- **100% means these 18 mutants.** It says nothing about mistakes nobody thought of. Most were caught at the first seed, so they are not hard cases. `AdmissionIgnoresObserved`, at seed 325, shows that subtle ones take many runs.
- **200,000 clean runs do not prove there are no bugs.** The last two bugs had a rate of about 1 in 1,000 and 1 in 5,500, so a rarer one could remain. Nightly CI runs 200,000 more from a random start seed, and uploads any failing schedule.
- **Faults are drawn from a fixed menu,** and one entity with one field of each kind. A bug that needs several registers may not appear.
- **`LwwWithoutHlc` is caught first by the drift bound, not causality.** A separate test, `A_write_that_saw_another_wins_even_from_a_device_with_a_slow_clock`, checks that it breaks causality too.
- **The nightly workflow has not run yet.** It starts once this is on `main`.
